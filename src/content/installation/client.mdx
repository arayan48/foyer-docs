L'appli se connecte à un agent, sur la même machine ou sur le réseau. Elle ne demande pas de droits administrateur.

## Télécharger

Depuis la [dernière version](https://github.com/arayan48/foyer/releases/latest) :

| Système | Fichier |
|---|---|
| Windows | `Foyer-Client.exe` |
| macOS | `Foyer-Mac.dmg` |
| Linux (Debian, Ubuntu) | `Foyer-Client-Linux.deb` |
| Linux (autres) | `Foyer-Client-Linux.AppImage` |

Sur la machine Windows qui héberge les jeux, inutile d'installer le client : `Foyer-Serveur.exe` contient déjà l'appli.

## Linux

```bash
sudo apt install ./Foyer-Client-Linux.deb
```

Ou, avec l'AppImage :

```bash
chmod +x Foyer-Client-Linux.AppImage && ./Foyer-Client-Linux.AppImage
```

## Mises à jour

L'appli vérifie les nouvelles versions au démarrage et propose de les installer. Elle met aussi à jour l'agent : les serveurs sont arrêtés proprement avant.
