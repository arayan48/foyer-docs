`Foyer-Serveur.exe` installe l'appli et l'agent sur la machine qui fera tourner les jeux.

## Installer

1. Téléchargez `Foyer-Serveur.exe` depuis la [dernière version](https://github.com/arayan48/foyer/releases/latest).
2. Lancez-le et acceptez la demande de droits administrateur.
3. Terminez l'assistant.

L'installeur :

- crée une tâche planifiée qui lance l'agent au démarrage de Windows, même sans session ouverte ;
- ouvre le port `7878` (TCP) dans le pare-feu Windows ;
- crée le dossier de données `C:\Foyer`.

## Fichiers créés

| Fichier | Rôle |
|---|---|
| `C:\Foyer\token` | Jeton à saisir dans l'appli |
| `C:\Foyer\fingerprint` | Empreinte du certificat, à comparer à la connexion |
| `C:\Foyer\cert.pem`, `key.pem` | Certificat HTTPS de l'agent |
| `C:\Foyer\servers.json` | Liste des serveurs |
| `C:\Foyer\servers\<id>\` | Fichiers de chaque serveur (monde, plugins, ressources) |
| `C:\Foyer\runtime\` | Java partagé par les serveurs Minecraft |

Pour lire le jeton :

```powershell
Get-Content C:\Foyer\token
```

## Systèmes pris en charge

Windows 10, Windows 11 et Windows Server, en 64 bits. Foyer est testé sur Windows Server 2025.

Pour une machine dédiée, Windows Server ou Windows 11 Pro conviennent tous les deux. Désactivez la mise en veille : un serveur en veille coupe les joueurs.
