Cada servidor tiene sus propios ajustes en la aplicación.

| Ajuste | Por defecto | Efecto |
|---|---|---|
| RAM | 4 GB | Minecraft: memoria dada a Java (`-Xms` y `-Xmx`), reservada desde el inicio. De 512 MB a 64 GB. FiveM: solo se usa si la RAM está limitada. |
| Limitar la RAM | No | Pone un tope a la memoria. Minecraft conserva un margen del 25 % (512 MB como mínimo) por encima de la RAM elegida, porque Java usa memoria fuera del heap. |
| Límite de procesador | Ninguno | Del 5 al 100 % del procesador de la máquina. |
| Núcleos | Todos | Asigna el servidor a ciertos núcleos, útil con varios servidores. |
| Inicio automático | No | Inicia el servidor al arrancar la máquina. |
| Reinicio tras un fallo | Sí | Reinicia tras 5 s, con un máximo de 3 intentos en 10 minutos. |
| Puerto | Según el juego | Minecraft: modificable con el servidor detenido. FiveM: se ajusta en txAdmin. |

## Varios servidores en una máquina

- Deje al menos 2 GB de RAM libres para el sistema.
- Asigne puertos diferentes a cada servidor.
- En un procesador de 8 núcleos o más, reparta los servidores en núcleos distintos para que no se estorben.

## Parada limpia

Foyer envía primero el comando de parada del juego (`stop` para Minecraft) y espera 30 segundos a que se guarde el mundo. Pasado ese plazo, se fuerza el cierre del proceso.
