The Foyer agent is light. The games are what need resources. So add up:

**Machine RAM = system + sum of the servers' RAM + headroom**

## Machine baseline

| | Minimum | Recommended |
|---|---|---|
| Processor | 2 cores, 64-bit | 4 cores or more, high clock speed (4 GHz and up in boost) |
| RAM kept for the system | 2 GB (Linux), 3 GB (Windows) | 4 GB |
| Disk | SSD, 20 GB free | NVMe SSD, 50 GB free or more |
| Network | Ethernet cable | Ethernet cable and fibre |

## What really matters

- **Clock speed before core count.** Minecraft and FiveM do most of their work on a single thread. A recent 4.5 GHz processor holds more players than an old 16-core at 2.4 GHz. Extra cores help you run several servers at once.
- **An SSD.** On a hard drive, Minecraft chunk loading and FiveM startup are much slower.
- **Cable rather than Wi-Fi.** Wi-Fi adds latency and packet loss.
- **Not too much RAM per server.** Beyond what is needed, extra RAM gains nothing and can lengthen Java garbage collection pauses.

## Example machines

Estimated orders of magnitude, not measurements. Test with your own plugins and scripts.

| Machine | What it handles well |
|---|---|
| Mini PC, 4 cores, 8 GB | One Minecraft server for 10 to 15 players, or a light FiveM server for 10 players |
| Desktop PC, 6 cores, 16 GB | Two Minecraft servers for 15 players each, or a 32-player FiveM RP server |
| Server, 8 cores, 32 GB | Several Minecraft servers, or a 48-player FiveM RP server with its database |

Details per game are in [Minecraft](/serveurs/minecraft) and [FiveM](/serveurs/fivem).
