## Ports utilisés

| Service | Port par défaut | Protocole | À ouvrir sur Internet ? |
|---|---|---|---|
| Agent Foyer | `7878` | TCP | **Non, jamais** |
| Minecraft | `25565` | TCP | Oui, pour les joueurs |
| FiveM | `30120` | TCP et UDP | Oui, pour les joueurs |
| txAdmin (FiveM) | port FiveM + 10000, soit `40120` | TCP | Non, sauf besoin |

L'agent ouvre et ferme lui-même les ports des jeux dans le pare-feu de la machine. La box internet, elle, reste à régler à la main.

## Faire venir des joueurs de l'extérieur

1. Donnez une IP fixe à la machine dans votre box (bail DHCP statique).
2. Dans la box, redirigez le port du jeu vers cette IP (NAT / redirection de ports).
3. Donnez aux joueurs votre IP publique, ou un nom de domaine.

Si votre box est derrière un CGNAT ou si vous ne voulez rien ouvrir, utilisez un tunnel comme [playit.gg](https://playit.gg).

## Gérer à distance

**N'exposez jamais le port `7878` sur Internet.** Pour gérer vos serveurs hors de chez vous, passez par un VPN : WireGuard, Tailscale, ou le VPN de votre box.

## Sécurité de la connexion

- Tout le trafic entre l'appli et l'agent est chiffré (TLS).
- L'appli épingle le certificat de l'agent : un certificat différent est refusé.
- Chaque requête, console comprise, exige le jeton dans l'en-tête `Authorization`.
