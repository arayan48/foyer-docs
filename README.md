# Documentation de Foyer

Documentation de [Foyer](https://github.com/arayan48/foyer) : installation, configuration et dimensionnement des serveurs de jeu.

Construite avec Next.js et [Once UI](https://once-ui.com). Les pages sont dans `src/content/` (MDX), l'ordre du menu dans les fichiers `meta.json`.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```
